HookFont

日系 Galgame 字体替换 / 汉化工具链 —— 启动游戏进程并注入 Hook DLL，强制把字体替换为指定字符集与字体，让日文游戏正确显示中文。

  • 强制字体替换 — Hook CreateFontA/W、CreateFontIndirectA/W 四个 API，统一替换字符集与字体
  • DirectWrite 引擎支持 — Hook IDWriteFactory::CreateTextFormat，覆盖 WPF / Unity 等现代渲染引擎游戏
  • 字体映射表 — [FontMap] 按"原字体 → 新字体"精确替换，优先于全局替换
  • 候选字体回退 — FontName 支持逗号分隔候选列表，自动选用首个系统已安装字体
  • Detours 注入 — 以挂起方式启动目标游戏并注入 Hook DLL，稳定可靠
  • 窗口标题替换 — 可选将游戏窗口标题替换为任意文本
  • 中文路径兼容 — 配置文件按程序自身目录解析，中文路径自动转 8.3 短路径
  • 日志排查 — 运行日志落盘（HookFont.log），异常可追查
